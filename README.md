# Modélisation et simulation sous MATLAB d’un système automatisé de tri d’objets

## 1. Présentation du projet
Ce projet consiste à modéliser et à simuler sous MATLAB un système automatisé de tri d’objets.

## 2. Objectifs
- Représenter graphiquement un système de tri.
- Simuler le déplacement des objets sur un tapis roulant.
- Développer une logique de tri automatique.
- Orienter les objets vers différents bacs selon un critère de tri défini.

## 3. Environnement de travail
- Logiciel : MATLAB R2018a.
- Type de réalisation : simulation numérique.
- Matériel physique : aucun.

## 4. Résultats attendus
Obtenir une simulation permettant de visualiser le déplacement des objets et leur tri automatique.

## 5. État d’avancement
Projet en cours de développement.
